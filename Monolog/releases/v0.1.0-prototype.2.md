# Monolog - Prototype 2: Autocorrect

## What's new

- English autocorrect for common typos and unambiguous dictionary corrections when entering space or punctuation. Backspace immediately to undo a correction.
- Autocorrect toggle in companion Settings → Keyboard → Typing, enabled by default.
- Autocorrect skips protected fields, incognito, email and URL fields, non-English typing, and fields that disable suggestions.
- Latest keyboard improvements, question answers in the suggestion strip, and the pencil-with-sparkle rewrite control.
- Journal questions use on-device Gemma with retrieved journal entries. Semantic search is available through its separate encoder download.
- Capture crop-preview and note-editor spacing changes, plus the optional Android accessibility context shortcut.

## Install

Download **Monolog-v0.1.0-prototype.2-arm64-v8a.apk**.

- Android 15+ (API 35), ARM64.
- Package: com.notokens.monolog.
- Version: 0.1.0-prototype.2; version code: 2.
- Signed with the same Monolog testing certificate as prototype.1, allowing an in-place update.
- This remains a signed debug prototype.
- AI models and the semantic-search encoder download separately. Hosted AI credentials are not bundled.

## Validation and limitations

- The debug APK build succeeded. No automated or device tests were run for this delivery, as requested; behavior still needs manual verification.
- Full yearly archive reclamation and temporary year-cache management remain unfinished. Automatic eviction remains disabled.
- Google OAuth remains in Testing and requires an allowed test account.

This is an APK-only prerelease. The source archives generated by GitHub reflect baseline commit a16f70cf3abb304a162a5636a848747c9d8ce5ec; the APK includes newer local changes that have not been pushed to the repository.
