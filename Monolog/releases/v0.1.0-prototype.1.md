# Monolog - First Signed Prototype

This is Monolog's first public prototype prerelease, published on 21 November 2026. It is the same APK installed on the development phone.

This is an APK-only publication. GitHub's automatically generated source archives reflect baseline commit a16f70cf3abb304a162a5636a848747c9d8ce5ec. The APK additionally contains local onboarding and journal-memory changes that have not been pushed to the repository.

## Download and install

Download **Monolog-v0.1.0-prototype.1-arm64-v8a.apk** from this release's assets.

- Android 15 or newer (API 35+), ARM64 devices.
- Package: com.notokens.monolog.
- APK version name: 1.0; version code: 1.
- Signed debug build for prototype evaluation, using the existing Monolog testing certificate. This is not a production-hardened build.
- To install, open the APK and allow installation from your browser or file manager when Android asks. An existing Monolog installation must use the same signing certificate to update in place.

## Included

- Monolog keyboard and companion journal with Paper and Ink themes.
- First-time setup for keyboard activation, memory preferences, appearance, and optional capture, microphone, and notification permissions.
- Screen capture with named notes, image pins, and quick shortcuts.
- Cleaner context library and readable note/pin cards.
- Journal memory screens with editable moments, keyword lookup, optional offline semantic search download, and on-demand recaps.
- Optional Google Sign-In and encrypted Google Drive backup and restore in companion Settings. Guest use remains available.
- Existing on-device AI integration and optional hosted AI configuration. AI models and the search encoder download separately; no hosted AI API key is bundled.

## Prototype limitations

- Full yearly archive reclamation, removable encrypted year caches, safe expiry while a year is open, and rollover UX are unfinished. Existing local data is retained and automatic eviction is disabled.
- The latest journal memory changes, multilingual search quality, and cross-phone recovery of the new memory payload have not been runtime-tested.
- Google OAuth is configured for testing; sign-in and Drive access require an allowed test account while the OAuth app remains in Testing.
- The APK compiled and packaged successfully. No new automated or device tests were run for this delivery, as requested.
